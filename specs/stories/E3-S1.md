# E3-S1 — Theme provider (branding to CSS tokens)

**Epic:** E3
**Layer:** UI
**Group:** C
**Depends on:** E1-S2

## Description

The web theme provider converts `branding` into CSS custom properties on `:root` (light plus derived dark values). Tailwind v4 references those tokens, and logo/name/favicon read from config. Rebranding never touches component code.

## Acceptance Criteria

1. At web startup, `branding.colors` are emitted as CSS custom properties on `:root` and a derived dark set is present.
2. Changing `colors.primary` and `productName` in config re-brands every screen with no component edits (verified by asserting the computed token value and the document title).
3. Logo (light/dark), favicon, typography font family, and radius come from config, not hardcoded values.
