# E3-S3 — Terminology (useTerm + term helper)

**Epic:** E3
**Layer:** UI
**Group:** C
**Depends on:** E1-S2

## Description

A `useTerm(key, { plural, capital })` hook and a `term()` server-side helper resolve platform nouns from config with a fallback to defaults. All platform screens, emails, and validation messages that name a platform noun use them.

## Acceptance Criteria

1. `useTerm("organization")` returns the configured singular; with `{ plural: true }` returns the plural; an unknown key falls back to a sensible default.
2. Setting `terminology.organization` to Clinic/Clinics changes the noun in settings screens, nav, and error messages with no component edits.
3. The server-side `term()` returns the same resolved value for use in emails and validation messages.
