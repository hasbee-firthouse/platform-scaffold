# E1-S4 — Core DB client & migration runner

**Epic:** E1
**Layer:** Repository
**Group:** B
**Depends on:** E1-S1

## Description

platform-db provides the Drizzle client, drizzle-kit config, an idempotent migration runner, and core schema conventions (uuid v7 PKs, created_at/updated_at). `pnpm db:migrate` runs on deploy before the app starts.

## Acceptance Criteria

1. `pnpm db:migrate` applies all committed migrations against Postgres and is idempotent (a second run makes no changes and exits 0).
2. The Drizzle client connects using `DATABASE_URL` and executes a `select 1` health query successfully.
3. Generated tables use uuid v7 primary keys and `created_at`/`updated_at` columns per convention.
4. `pnpm db:generate` produces a migration file from the current Drizzle schema.
