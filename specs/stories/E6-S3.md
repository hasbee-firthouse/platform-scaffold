# E6-S3 — Isolation & migration test suite

**Epic:** E6
**Layer:** Service
**Group:** I
**Depends on:** E6-S1, E6-S2

## Description

The CI suite proving cross-tenant isolation at the app layer and via RLS independently, plus migration idempotency.

## Acceptance Criteria

1. Every org-scoped endpoint called with org A’s session against org B’s ids returns 404/403 and never leaks data.
2. A direct-SQL test proves RLS blocks cross-tenant reads even when app scoping is bypassed.
3. A migration idempotency test proves running `db:migrate` twice on a fresh DB yields no diff on the second run.
