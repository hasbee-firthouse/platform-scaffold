# E5-S3 — Organization UI (switcher, members, invitations, roles)

**Epic:** E5
**Layer:** UI
**Group:** G
**Depends on:** E5-S2, E3-S4

## Description

Org switcher, members admin, invitations, a read-only roles matrix, and org settings screens, with visibility per role and capabilities.

## Acceptance Criteria

1. The org switcher appears only when the user has more than one org, and the active org is encoded in the URL (`/o/:orgSlug/...`).
2. The Members screen lists members and supports role change, remove, and admin-create (which sends a set-password email); it assigns exactly one role per member.
3. The Invitations screen lists pending invites with resend/revoke; the Roles & Permissions screen shows a read-only matrix of the code-defined roles.
