# E8-S5 — Deployment, deletability & fork story

**Epic:** E8
**Layer:** Config
**Group:** J
**Depends on:** E8-S3, E8-S4, E2-S1

## Description

The multi-stage Dockerfile + docker-compose (postgres + mailpit) + seed, docs/FORKING.md, proof that deleting the reference module leaves the platform green, and the acceptance table. Closes the fork story.

## Acceptance Criteria

1. `docker compose up` then `pnpm db:migrate && pnpm seed && pnpm dev` runs locally, and the production image builds and boots serving both API and SPA.
2. Deleting `modules/reference-workspace` and its registry line, then `pnpm db:generate`, leaves the platform building, migrating, and passing platform tests.
3. `docs/FORKING.md` walks through the Section 24 fork procedure; the seed is dev-only and refuses to run when NODE_ENV=production.
