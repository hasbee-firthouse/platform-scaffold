# E8-S2 — Workspace & task API services

**Epic:** E8
**Layer:** Service
**Group:** H
**Depends on:** E8-S1, E6-S1, E2-S3

## Description

Org-scoped CRUD services for workspaces and tasks with per-route permission enforcement, a membership-aware assignee, the task-limit entitlement, audit, and RLS coverage. Every interaction hits the real stack; nothing is mocked.

## Acceptance Criteria

1. Workspace list/create/rename/delete and task add/complete/uncomplete/delete/open-done-filter work under `/api/orgs/:orgId/workspace/...` with the declared permissions enforced.
2. Assigning a task to an org member succeeds; assigning a non-member (or a removed member) is rejected.
3. Creating a task beyond `workspace.maxTasks` returns `ENTITLEMENT_REQUIRED`.
4. Workspace created/deleted events are written to the audit log, and both tables are covered by the isolation suite.
