# E6-S1 — Scoped db factory & membership middleware

**Epic:** E6
**Layer:** Repository
**Group:** G
**Depends on:** E1-S4, E5-S2

## Description

platform-tenancy scoped-db factory withOrg(orgId, tx => ...) opens a transaction and runs SET LOCAL app.org_id (pooler-safe), and middleware verifies the session user’s membership in :orgId before any handler runs.

## Acceptance Criteria

1. `withOrg(orgId, cb)` opens a transaction, executes `SET LOCAL app.org_id = $orgId`, and passes the scoped client to the callback.
2. Middleware on `/api/orgs/:orgId/...` returns 404 (not 403) when the session user is not a member of `:orgId`, before any handler runs.
3. No tenant-table query path exists outside `withOrg` (verified by an architecture/grep test).
