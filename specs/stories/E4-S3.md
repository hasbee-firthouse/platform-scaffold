# E4-S3 — Auth screens & end-to-end flows

**Epic:** E4
**Layer:** UI
**Group:** F
**Depends on:** E4-S2, E3-S4, E2-S2

## Description

Sign in / sign up, verify email, forgot/reset password, accept invite, and magic-link (when enabled) screens, plus the end-to-end verification, reset, sign-out and session-revocation flows, with rate limits and failed-sign-in auditing.

## Acceptance Criteria

1. Email/password signup sends a verification email (visible in Mailpit); the account cannot password-sign-in until verified; verifying establishes a session.
2. Password reset via an emailed link sets a new password and invalidates the old one.
3. "Sign out other sessions" in Security settings revokes the other sessions (subsequent requests from them return 401).
4. Auth endpoints are rate-limited (429 `RATE_LIMITED` past the threshold) and failed sign-ins are audited.
