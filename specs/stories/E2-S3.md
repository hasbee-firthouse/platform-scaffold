# E2-S3 — Audit log schema, writer & platform events

**Epic:** E2
**Layer:** Service
**Group:** D
**Depends on:** E1-S4, E2-S1

## Description

Append-only audit_log table plus a writer exposed on PlatformContext. The platform emits the documented events; modules write via ctx.audit.log.

## Acceptance Criteria

1. `audit_log` has columns id, org_id (nullable), actor_user_id (nullable), action, target_type, target_id, metadata jsonb, ip, user_agent, created_at; the writer offers no update or delete path.
2. `ctx.audit.log(...)` writes a row capturing action, target, actor, and the request ip/user-agent.
3. Sign-in success, sign-in failure, and sign-out produce audit rows with the correct action codes.
