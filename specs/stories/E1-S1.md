# E1-S1 — Monorepo, tooling & CI skeleton

**Epic:** E1
**Layer:** Config
**Group:** A
**Depends on:** (none)

## Description

Establish the pnpm + Turborepo monorepo with the packages/apps/modules layout, strict TypeScript ESM, ESLint flat config, Prettier, Vitest, and a GitHub Actions CI skeleton. This is the substrate every other package builds on.

## Acceptance Criteria

1. `pnpm install` at the repo root resolves all workspace packages under `packages/*`, `apps/*`, and `modules/*` with zero errors.
2. `pnpm -w tsc --noEmit` runs across all workspaces under TypeScript 5.x `strict` + ESM and exits 0 on the skeleton.
3. `pnpm lint` (ESLint flat config) and `pnpm format --check` (Prettier) run and pass on the skeleton.
4. A GitHub Actions workflow runs lint, typecheck, and `vitest run` on push and completes green on the skeleton.
