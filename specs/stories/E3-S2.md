# E3-S2 — platform-ui component library

**Epic:** E3
**Layer:** UI
**Group:** D
**Depends on:** E3-S1

## Description

A token-driven, accessible component library owned in-repo: button, input, select, dialog, dropdown, table, tabs, toast, card, form primitives, empty-state, confirm-dialog. Components consume only theme tokens, never literal colors.

## Acceptance Criteria

1. Each listed component renders and consumes theme tokens only — a check finds no literal hex colors in `packages/platform-ui` component styles.
2. Dialog and dropdown manage focus (trap plus restore on close) and are keyboard-operable (Esc closes, Tab cycles).
3. Form primitives integrate with react-hook-form + a Zod resolver and surface validation errors with associated labels.
