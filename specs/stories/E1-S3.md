# E1-S3 — Shared contracts, error envelope & pagination

**Epic:** E1
**Layer:** Types
**Group:** B
**Depends on:** E1-S1

## Description

platform-contracts exports shared Zod schemas: the stable error envelope with machine-readable codes, and pagination request/response shapes. Both apps/api and apps/web consume these so client and server validate identically.

## Acceptance Criteria

1. The error envelope schema is `{ error: { code, message, details? } }` and the code enum includes UNAUTHENTICATED, FORBIDDEN, NOT_FOUND, VALIDATION_FAILED, ENTITLEMENT_REQUIRED, CONFLICT, RATE_LIMITED, and INTERNAL.
2. The pagination request schema defaults `limit` to 25, caps it at 100, accepts `offset`; the response schema is `{ items, total }`.
3. The contracts package is importable by both `apps/api` and `apps/web` and typechecks in each.
