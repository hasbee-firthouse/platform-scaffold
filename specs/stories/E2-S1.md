# E2-S1 — API runtime & composition root

**Epic:** E2
**Layer:** API
**Group:** C
**Depends on:** E1-S2, E1-S3, E1-S4

## Description

apps/api Fastify composition root iterates the module registry to mount plugins, serves the built SPA with history fallback, exposes health/ready, wires the Zod type provider + OpenAPI + error-envelope handler + pino logging, validates env at boot, and shuts down gracefully.

## Acceptance Criteria

1. `GET /api/health` returns 200 (liveness) and `GET /api/ready` returns 200 only when the DB ping succeeds (503 otherwise).
2. Boot fails fast with a descriptive error when a required env var (DATABASE_URL, APP_URL, BETTER_AUTH_SECRET, NODE_ENV) is missing.
3. In dev, OpenAPI UI is served at `/api/docs` reflecting registered routes; a thrown handler error returns the `{ error: {...} }` envelope and never a stack trace in prod.
4. Unknown non-API GET routes return the SPA `index.html` (history fallback); SIGTERM drains connections and closes the pool.
