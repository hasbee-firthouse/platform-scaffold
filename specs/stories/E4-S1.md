# E4-S1 — Identity port & better-auth adapter

**Epic:** E4
**Layer:** Service
**Group:** C
**Depends on:** E1-S4, E1-S2

## Description

platform-identity is a port with a better-auth adapter: email/password (verification required), Google OAuth, the organization plugin, magic-link gated by capability, cookie sessions, and account linking. The schema is generated into platform-db. Nothing outside platform-identity imports better-auth.

## Acceptance Criteria

1. Nothing outside `platform-identity` imports `better-auth` (a repository grep check passes).
2. better-auth is configured with email/password, Google provider, and the organization plugin; the magic-link plugin is registered only when `capabilities.magicLink` is true.
3. Sessions are cookie-based, httpOnly, SameSite=Lax, Secure in prod, with 30-day sliding expiry and revocable via the session table; no JWT is sent to the browser.
4. Account linking merges a Google sign-in and a password account that share a verified email into one user.
