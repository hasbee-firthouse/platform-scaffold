# E8-S3 — Workspace web screens

**Epic:** E8
**Layer:** UI
**Group:** I
**Depends on:** E8-S2, E3-S4

## Description

Workspace list/create/rename/delete and a per-workspace task screen (add, complete/uncomplete, delete, open/done filter, and an assignee picker over org members) using terminology and platform-ui tokens.

## Acceptance Criteria

1. The task screen adds, completes/uncompletes, and deletes tasks and filters by open/done, each hitting the real API.
2. The assignee picker lists current org members and assigns a task to one.
3. Screens use `useTerm` for module nouns and platform-ui tokens (no literal colors); reaching the task limit shows the upgrade notice.
