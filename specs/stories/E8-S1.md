# E8-S1 — Reference module contracts, schema & manifest

**Epic:** E8
**Layer:** Types
**Group:** G
**Depends on:** E1-S3, E5-S1, E7-S1

## Description

reference-workspace shared Zod contracts, the Drizzle schema (workspace, task), and the ModuleManifest declaring permissions, the Workspace Manager role, and the workspace.maxTasks entitlement. This is the deletable proof of the foundation.

## Acceptance Criteria

1. The schema defines `workspace(id, org_id, name, created_by, timestamps)` and `task(id, org_id, workspace_id, title, status open|done, assignee_member_id nullable FK->member, due_date nullable, created_by, timestamps)`.
2. The manifest declares permissions `workspace.workspaces.manage`, `workspace.tasks.read`, `workspace.tasks.write`, the `Workspace Manager` role, and the entitlement `workspace.maxTasks` (default 100).
3. The module’s Zod contracts appear in the generated OpenAPI document.
