# E7-S3 — Audit Log viewer screen

**Epic:** E7
**Layer:** UI
**Group:** F
**Depends on:** E2-S3, E5-S1, E3-S4

## Description

The Settings -> Audit Log screen: filterable, paginated, admin-gated, and org-scoped by RLS like everything else.

## Acceptance Criteria

1. The Audit Log screen requires an admin permission (403 or hidden otherwise) and lists audit rows for the active org only.
2. Rows are paginated (limit/offset, `{ items, total }`) and filterable by action and actor.
3. Because it is org-scoped by RLS, it never shows another org’s events.
