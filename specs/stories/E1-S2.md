# E1-S2 — Product config schema, profiles & startup validation

**Epic:** E1
**Layer:** Config
**Group:** B
**Depends on:** E1-S1

## Description

Implement platform-config: the `defineProduct` factory and a Zod schema covering branding, capabilities, profiles, terminology, navigation, and email identity. The config is validated at startup and the process refuses to boot on an invalid config, with a precise path-level error.

## Acceptance Criteria

1. `defineProduct` with a valid config parses to a typed product object; the three profiles (`b2c-simple`, `b2b-standard`, `b2b-enterprise`) apply their documented capability defaults.
2. Loading an invalid config (e.g. missing `branding.colors.primary`) throws a Zod error naming the offending path and the process exits non-zero.
3. An explicit capability override (e.g. `personalAccounts: true` on `b2b-standard`) wins over the profile preset.
4. `b2b-enterprise` resolves `capabilities.enterpriseEntitlements` to `true`.
