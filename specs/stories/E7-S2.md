# E7-S2 — Operator CLI

**Epic:** E7
**Layer:** Service
**Group:** G
**Depends on:** E7-S1, E2-S3

## Description

The `pnpm ops` CLI covering entitlement set/get/list, org list/restore, user deactivate, and invite resend. It runs against DATABASE_URL and audits every mutation with actor system:cli.

## Acceptance Criteria

1. `pnpm ops entitlement set <org> <key> <value>` writes the override and `... get`/`... list` read it back.
2. `pnpm ops org list` and `org restore <id>` work; restore clears `deleted_at` within the retention window.
3. Every mutating command writes an audit row with actor `system:cli`.
