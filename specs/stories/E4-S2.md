# E4-S2 — Auth API mount, session middleware & /api/me

**Epic:** E4
**Layer:** API
**Group:** D
**Depends on:** E4-S1, E2-S1

## Description

Mount better-auth under /api/auth/* via the identity package, expose getSession/requireUser middleware, and serve the /api/me session bootstrap returning the user, orgs, active-org role, and permission set.

## Acceptance Criteria

1. `/api/auth/*` routes are mounted and reachable; no other plugin references better-auth directly.
2. `requireUser` on a protected route returns 401 `UNAUTHENTICATED` without a valid session and passes through with one.
3. `GET /api/me` returns the user, their orgs, the active-org role, and the resolved permission set.
