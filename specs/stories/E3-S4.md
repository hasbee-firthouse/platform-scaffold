# E3-S4 — Web app shell & route assembly

**Epic:** E3
**Layer:** UI
**Group:** E
**Depends on:** E3-S2, E3-S3, E2-S1

## Description

apps/web shell wires theme, terminology, TanStack Query, and TanStack Router providers, assembles the route tree from module manifests, renders the sidebar nav from manifests plus navigation config, and provides error/404/upgrade-notice surfaces.

## Acceptance Criteria

1. The router assembles module route trees from the registry; a module’s `webRoutes` appear under `/o/:orgSlug/<module>` (or `/app/<module>` for personal-only).
2. The sidebar nav renders manifest `nav` contributions, honoring `navigation.order` and `navigation.hidden` from config.
3. Navigating to an unknown route renders the 404 surface; an ENTITLEMENT_REQUIRED response renders the upgrade-notice surface.
