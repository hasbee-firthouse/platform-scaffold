Design gate · visual contract

UI mockups

Eight interactive, self-contained mockups covering the UI-layer stories. Aesthetic: Platform Console — indigo primary, slate surfaces, Inter for UI, a monospace face for all technical metadata. Every color is a CSS custom property (the E3-S1 theming contract), so each screen carries a light/dark toggle and, where relevant, a state switch (happy / empty / error). Field names follow SPEC §19; API captions follow §15.
