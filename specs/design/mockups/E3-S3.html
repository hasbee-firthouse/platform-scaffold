One noun, three surfaces

The same platform noun resolves through useTerm("organization") everywhere. Flip the config above — nav, the settings heading, and the validation message all relabel with zero component edits. The server helper term() returns the identical string for emails.

useTerm("organization")"Organization"
useTerm("organization", { plural: true })"Organizations"
useTerm("organization", { capital: false })"organization"
useTerm("sprocket")  // unknown key"sprocket" (fallback)
